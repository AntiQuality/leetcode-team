# LeetCode-Team

macOS 力扣国服客户端：在官方网页中刷题，通过 GitHub 私有仓库共享 Hot 100 小队进度。独立开源项目，非力扣官方产品。

## 功能

- 内嵌力扣国服网页，登录、编写代码、运行和提交。
- Hot 100 题单、专题筛选和累计通过进度。
- 小队成员进度展示，每位成员独立保存记录。
- GitHub 网页授权、钥匙串保存会话和自动续期。
- 可隐藏、悬浮预览的侧边栏和原生窗口按钮。

## 使用

1. 下载 Release 安装包，解压并打开 App，在右侧登录力扣。
2. 在「小队」点击「登录 GitHub」，使用客户端显示的设备码完成网页授权。
3. 房主在 GitHub 创建名为 `leetcode-team-sync` 的私有仓库，包含 README。
4. 房主为该仓库安装项目的 GitHub App，选择 **Only select repositories**，仅选择小队仓库。
5. 回到客户端点击「连接并初始化小队」。
6. 房主通过「邀请成员」在 GitHub 邀请指定账号；队员接受邀请后，在客户端连接 `房主/leetcode-team-sync`。

邀请绑定指定 GitHub 账号，仓库地址本身不授予访问权限。房主通过成员卡片的「移除成员」前往 GitHub 撤销协作者权限；已共享的历史进度和已下载的数据不会删除。

## 数据与权限

GitHub App 仅请求 Contents 读写和必要的 Metadata 读取，不请求 Administration 或组织权限。客户端校验安装范围为单个私有小队仓库。

共享记录包含力扣主页标识、已通过题目和更新时间，不上传力扣登录凭证或题解源码。累计通过记录合并本地与远端状态；提交冲突后重新读取并有限重试。主页标识变化时，需要确认是否为同一账号改名。

GitHub 会话保存在本机钥匙串，启动时静默恢复并自动续期。退出登录清除本机会话。钥匙串不可用时退回网页登录，不自动弹出密码框。当前使用 ad-hoc 签名，升级后可能需要重新登录。

## 构建与测试

要求 macOS 12 及以上和 Swift 工具链：

```sh
bash test.sh
bash build.sh
```

构建输出为 `LeetCode-Team.app`，使用当前机器架构。Release 安装包面向 Apple Silicon，尚未进行 Apple Developer ID 签名和公证。

测试覆盖题单状态解析、账号改名确认、仓库权限、冲突重试、累计进度合并及侧栏状态。真实多客户端并发和长期会话续期仍需进一步验证。

GitHub App 维护说明见 [GITHUB-APP-SETUP.md](GITHUB-APP-SETUP.md)。
